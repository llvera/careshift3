# CareShift 3

小規模多機能型居宅介護の月間シフト作成・検証用Webアプリ。中文・日本語切替に対応します。

## 在线演示

发布后地址：https://llvera.github.io/careshift3/

## 功能与当前规则

- 管理者维护员工、兼职/司机当月可出勤日期和时间、希望休、有休、生日假、锁定班次及跨月信息。
- 早班组合至少3人、08:30前至少2人在岗。1010和1011均早段出勤时，留一名正社员早班或管理者半勤即可；不要求08:00–12:00持续3人。
- 17:00–19:00持续至少3人，优先补足晚间空缺。司机及轻作业不计现场。
- 所有员工连勤不超过5天，含管理员登记的上月末连续勤務。
- 禁止晚→早、晚→中、中→早、中→中。手动或锁定班次违规会报告硬性错误。
- 中班仅在排除中班后早班组合、晚间覆盖均不足3人时使用；每人每月最多2次、每日最多1人、周日不安排。
- 普通正社员两连夜勤后两天恢复公休；1009采用每月2次单夜勤，每次后两休。月末夜勤与上月末记录需在跨月设置中登记。
- 通常每月公休10天、2月9天；生日假和有休额外计休。当前公休仍作为优化目标，未满足时会提示。
- 司机时间由管理员登记；上午缺口由1003/1004早班补位，下午缺司机仍按设施规则显示提醒。
- 只有所有硬约束通过，才标记为合法候选。有限搜索未找到合法候选不等于已证明无解。

## 数据与备份

员工和排班保存在当前浏览器的 localStorage（careshift-v3）。在线演示不会自动读取本机其他地址的数据。使用“备份数据”导出JSON，或“恢复备份”在新地址导入。不同月份的班表应分别备份。请勿提交真实员工备份到公开仓库。

## 本地运行与测试

在项目目录运行：

```sh
python3 -m http.server 4174 --bind 127.0.0.1
```

访问 http://127.0.0.1:4174/ 。安装Node.js后运行：

```sh
node tests/run.cjs
```

## GitHub Pages

仓库Settings → Pages → Source选择GitHub Actions。推送main后，工作流先执行测试，再仅将index.html、app.js、i18n.js、styles.css和.nojekyll发布到Pages。真实备份、截图和本地调试文件均不在发布列表内。

## 已知边界

目前为启发式搜索原型，尚未接入完整约束求解器。不保证找到所有可行解。休憩仅扣工时，尚未精确安排休憩区间；班次、部分员工资格例外仍使用设施模板和固定工号。跨月信息由管理者登记。没有服务器数据库、账号权限或多人同步。

详细变更见 [CHANGES.md](CHANGES.md)。
